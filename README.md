# Simple-Calculator
## Description
A simple Python calculator that performs basic arithmetic operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero and invalid inputs.

## Requirements
- Python 3

## How to Run
1. Download `Simple Calculator.py`.
2. Open a terminal.
3. Run the command:

   ```bash
   python "Simple Calculator.py"
   ```

4. Enter two numbers and select an operation.
